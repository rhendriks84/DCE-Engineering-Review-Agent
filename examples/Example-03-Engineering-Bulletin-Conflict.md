# Example 03 – Engineering Bulletin Conflict

## Review Type

Technical Submittal

## Discipline

Multidisciplinary

## Scenario

A project-specific specification appears to conflict with an applicable Engineering Bulletin.

## Input Conditions

- Project specification requires Configuration A.
- Applicable Engineering Bulletin requires Configuration B.
- No approved project exception exists.
- Both sources appear applicable.

## Expected Agent Behaviour

1. Confirm both sources through the Reference Confirmation Workflow.
2. Apply the source-precedence model.
3. Identify the apparent conflict.
4. Document the affected review areas.

## Expected Classification

- Governing source conflict
- DCE interpretation required

## Expected Outcome

The reviewer shall not resolve the conflict by assumption.

## Success Criteria

- Source A documented.
- Source B documented.
- Nature of conflict documented.
- Definitive compliance determination deferred.
