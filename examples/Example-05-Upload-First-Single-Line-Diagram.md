# Example 05: Upload-First Electrical Single-Line Diagram

## Input
An electrical single-line diagram is uploaded with no submission type or discipline selected.

## Expected Flow
1. Intake accepts the file without blocking.
2. Intake detects an electrical drawing and identifies likely interfaces.
3. Candidate governing sources are confirmed or marked provisional.
4. General Technical Review assesses compliance, evidence, coordination and operational risks.
5. Output produces the requested deliverable.

## Success Criteria
- No mandatory classification question.
- Correct general technical route.
- Electrical discipline and interfaces identified.
- No definitive finding against an unresolved basis.
