\# Security Policy



\## Repository Purpose



The DCE Engineering Review Agent repository contains architecture, governance, workflow, evaluation, and agent\\-design assets intended to support structured engineering\\-review activities.



This repository is a public demonstration repository and must not contain confidential Microsoft, customer, vendor, project, operational, or security\\-sensitive information.



\## Information That Must Not Be Committed



Do not commit:



\- Microsoft Confidential or Highly Confidential content

\- Project\\-specific drawings, calculations, models, reports, specifications, or review comments

\- Internal standards not approved for public release

\- Vendor\\-confidential information

\- Customer information

\- Personal information

\- Credentials, passwords, keys, certificates, tokens, secrets, or connection strings

\- Internal SharePoint, Teams, Azure DevOps, GitHub Enterprise, or other private links

\- Security\\-sensitive datacentre information

\- Facility access, security, or operational procedures



\## Approved Repository Content



The repository may contain:



\- Architecture documentation

\- Governance documentation

\- Evaluation criteria

\- Agent instructions

\- Prompt and skill definitions

\- Validation workflows

\- Synthetic examples

\- Redacted examples approved for public release



\## Reporting Security Issues



If a potential security issue or information exposure is identified:



1\. Do not create a public issue containing sensitive information.

2\. Contact the repository owner directly.

3\. Remove exposed material immediately.

4\. Rotate affected credentials before reporting closure.

5\. Verify repository history does not retain exposed secrets.



\## Governance



The DCE Engineering Review Agent provides evidence\\-based, non\\-binding engineering\\-review support.



Final approval, deviation, waiver, and disposition authority remains with the authorised DCE engineer or governance authority.



The repository must never imply that final engineering authority resides with the agent.
