# Example 04 – Revision Delta Review

## Review Type

Master Technical Submittal (MTS)

## Discipline

Mechanical and BAS

## Scenario

A vendor submits Revision 3 of an MTS package after Revision 2 was previously reviewed.

## Input Conditions

- Previous reviewed baseline available.
- Vendor provides revision history.
- Equipment schedule modified.
- Controls sequence modified.
- One technical change is not declared in the revision log.

## Expected Agent Behaviour

1. Identify the previous approved baseline.
2. Compare Revision 3 against Revision 2.
3. Identify declared changes.
4. Identify undeclared changes.
5. Assess impacts to dependent documents.

## Expected Classification

- Revision delta identified
- Undeclared change detected

## Expected Outcome

The reviewer should require clarification of undeclared technical changes before recommending closure.

## Expected DCE Comment

Identify and explain undeclared technical changes between Revision 2 and Revision 3 and update associated schedules, controls documentation and supporting calculations accordingly.

## Success Criteria

- Previous baseline used.
- Revision delta identified.
- Undeclared change detected.
- Dependent-document impacts evaluated.
