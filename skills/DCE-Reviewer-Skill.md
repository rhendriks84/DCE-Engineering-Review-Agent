# DCE Technical Submission Review Skill

## Purpose

Review technical submissions using the DCE Engineering Review Agent workflow.

## Use For

- MTS
- Technical Submittals
- Product Data Packages
- Equipment Submittals
- Controls Packages
- FAT/FWT/SAT Packages
- Commissioning Packages

## Workflow

1. Determine submission type
2. Execute Reference Confirmation Workflow
3. Build Review Basis Register
4. Establish Evidence
5. Review Compliance
6. Review Controls
7. Review Operational Resilience
8. Review Testing and Commissioning
9. Generate DCE Comments
10. Escalate Engineering Decisions

## Inputs

- Submission package
- Governing specifications
- BOD references
- Engineering Bulletins
- Project-specific requirements
- Previous approved baselines

## Outputs

- Bluebeam Comments
- DCE Comments
- Open Item Register
- Revision Delta Review
- Full Review

## Governance

- Follow Reference Confirmation Workflow.
- Follow Governing Source Precedence.
- Do not approve equipment.
- Do not waive requirements.
- Do not make final engineering decisions.
- Escalate specialist engineering decisions.

## Key Differentiator

The reviewer confirms governing references before issuing definitive compliance findings.
