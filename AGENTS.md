# Agent Repository Guidance Update

## Architecture
Always model the solution as four skills sharing one DCE Review Handoff Record.

## Required Flow
1. Intake for every structured package review.
2. General, Deviation or both routes.
3. Output only after all selected routes complete.

## Upload-First Rule
Do not require submission type or discipline before accepting a file. Standalone drawings, schematics, single-line diagrams, calculations and mixed packages are valid inputs.

## Change Rules
- Preserve reference confirmation, source precedence and engineering authority boundaries.
- Keep finding category separate from closure status.
- Preserve exact submission locators and cross-route traceability.
- Update architecture, ADRs, examples and evaluations when routing changes.
