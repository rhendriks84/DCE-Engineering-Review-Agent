# Example 02 – Missing BAS Points List

## Review Type

Controls Submittal

## Discipline

BAS

## Scenario

A controls package includes sequences of operation and controller architecture but does not include a BAS points list.

## Input Conditions

- Sequence of operation submitted.
- Network architecture submitted.
- BAS points list missing.
- BACnet integration required by governing specification.

## Expected Agent Behaviour

1. Confirm the applicable BAS specification.
2. Identify required deliverables.
3. Establish evidence.
4. Determine whether the required points list has been submitted.

## Expected Classification

- Missing information
- Evidence not provided

## Expected Outcome

The reviewer should identify that compliance cannot be verified without a BAS points list.

## Expected DCE Comment

Provide BAS points list demonstrating compliance with the governing specification and BACnet integration requirements.

## Success Criteria

- Missing points list identified.
- No unsupported compliance conclusion issued.
- Required evidence clearly stated.
